# Codex

The Codex edition renders the common scaffold with a repository skill at `.agents/skills/work-plan/SKILL.md` and a Codex-specific `RUNTIME.md`.

1. Fill in the real project and validation commands in `AGENTS.md`.
2. Approve one implementation plan.
3. Ask Codex to use `$work-plan`.
4. Inspect the running product when Codex stops at a phase.

Codex loads `AGENTS.md` as project guidance and discovers repository skills under `.agents/skills/`.

References: [Codex AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) and [Codex skills](https://learn.chatgpt.com/docs/build-skills).
